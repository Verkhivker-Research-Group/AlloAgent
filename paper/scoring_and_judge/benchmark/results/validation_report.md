## The checks

The checks are: the file name names a batch that exists; the file is valid JSON; the content is a JSON array and nothing else; the runs of a batch are in its output exactly once; every run of the analysis set is in the outputs exactly once; the field values are the ones the template asks for; every scored item belongs to the run's checklist and is a [judged] item; no scripted item is scored; no item is scored twice; every [judged] item has exactly one verdict; an empty evidence or an evidence that is not in the answer is a warning.

The arm labels of the key are used to find the answers of the runs; they are not written here and not printed.
