# Arm D exposed tool list.
#
# One tool name per line. `#` comments are ignored, blank lines are
# skipped. This file is the FROZEN list of tools arm D may call: the
# agent's tool registry and system prompt are filtered down to exactly
# these names by `biomni.tool._registration.apply_exposed_tools`.
#
# Everything else stays REGISTERED (so it is discoverable, testable and
# callable by an explicit import) but is not EXPOSED to arm D.
#
# Rules applied when this list was frozen:
#   * T1-T10 and B1-B3 are the verified allosteric evaluation tools.
#   * B2 (dock_ligand_vina) states in its docstring that the returned
#     poses are hypotheses.
#   * The ported allosteric-domain functions are exposed only where
#     their known-answer test passes.
#   * literature (search_google / query_scholar) scrapes a search
#     engine, so it is NOT exposed to arm D.
#   * query_opentarget_genetics is NOT exposed: the OpenTargets
#     Genetics API host no longer resolves.
#   * query_chatnt (transformers) and the genomics tools that need
#     scanpy are registered but NOT exposed.
